# Real-Life Patch Notes: The Comedy Changelog

One line, at most 160 characters: a software patch note for a bug in real
life / human biology, in the terse register of a real release note.

> v2.1.0: fixed a bug where a sneeze retried itself twice because the first attempt failed to commit.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (falls back to `./output/entry.txt`
if `/output` is not writable) and prints it.

## Why it's funny

A sneeze almost never comes alone — it fires two or three times, as if the
first one didn't take. Told as a release note, that's a retry loop: the body
re-ran the sneeze because the first attempt "failed to commit".
